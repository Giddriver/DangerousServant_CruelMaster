# Dangerous Servant / Cruel Master

A turn-based strategy game. Open `index.html` in any browser. No install or build.

Dominate people across six institutions of Caldreth using a bound Illithid. Each thrall occupies your mind strength. The Illithid pushes every turn and sometimes spikes. If your free mind is below the push, shed thralls or lose. Reach 100 Subversion with the Collegium's Provost held, then confront the High Magister.
